## Overview

The CO2 Monitor is built as a Progressive Web App (PWA), enabling users to install it on their devices and access certain features offline. This provides a native app-like experience directly from the web browser.

## Web App Manifest

The application includes a `manifest.json` file that defines PWA metadata:

```json public/manifest.json
{
  "short_name": "CO2 Monitor",
  "name": "Sistema de Monitoreo de CO2",
  "icons": [
    {
      "src": "favicon.ico",
      "sizes": "64x64 32x32 24x24 16x16",
      "type": "image/x-icon"
    },
    {
      "src": "logo192.png",
      "type": "image/png",
      "sizes": "192x192"
    },
    {
      "src": "logo512.png",
      "type": "image/png",
      "sizes": "512x512"
    }
  ],
  "start_url": ".",
  "display": "standalone",
  "theme_color": "#000000",
  "background_color": "#ffffff",
  "version": "1.0.0"
}
```

## Icon Configuration

The manifest defines multiple icon sizes for different device contexts:

| Size | File | Purpose |
|------|------|----------|
| 16x16 - 64x64 | `favicon.ico` | Browser tabs, bookmarks |
| 192x192 | `logo192.png` | Android home screen, notifications |
| 512x512 | `logo512.png` | High-resolution displays, splash screens |

<Info>
Multiple icon sizes ensure the app looks sharp on all devices, from mobile phones to high-DPI desktop displays.
</Info>

## HTML Integration

The manifest is linked in the HTML head:

```html public/index.html
<link rel="manifest" href="%PUBLIC_URL%/manifest.json" />
<link rel="apple-touch-icon" href="%PUBLIC_URL%/logo192.png" />
<meta name="theme-color" content="#000000" />
<meta name="description"
  content="Sistema de monitoreo de CO2 para invernaderos. Monitorea los niveles de CO2 en tiempo real para un ambiente saludable y controlado." />
```

## Installation Experience

### Desktop Installation

On desktop browsers (Chrome, Edge), users can install the app via:
1. Browser's install button in the address bar
2. Settings menu → "Install CO2 Monitor"

### Mobile Installation

**Android (Chrome)**
- "Add to Home Screen" prompt appears automatically
- Manual: Menu → "Add to Home Screen"

**iOS (Safari)**
- Tap Share button
- Select "Add to Home Screen"
- Enter name and confirm

<Note>
iOS has limited PWA support compared to Android. Service worker functionality may be restricted.
</Note>

## Offline Capabilities

<Warning>
The current implementation does not include a service worker, which means:
- The app requires an active internet connection to function
- Real-time data fetching depends on API availability
- No offline caching of historical data
</Warning>

### Adding Service Worker Support

To enable offline capabilities, a service worker would need to be implemented to:

1. **Cache static assets** (HTML, CSS, JS)
2. **Cache API responses** for offline viewing
3. **Implement background sync** for data updates
4. **Handle network failures gracefully**

Create React App includes service worker support that can be enabled in `src/index.js`:

```javascript
// Currently disabled
import * as serviceWorkerRegistration from './serviceWorkerRegistration';

// To enable:
serviceWorkerRegistration.register();
```
