## API Endpoint Configuration

The CO2 Monitor fetches real-time data from a remote API endpoint. The API configuration is located in the `CO2Dashboard.js` component.

### Default API Endpoint

The application uses the following API endpoint:

```javascript
https://co2-api.vercel.app/api/co2
```

This endpoint is called on line 41 of `src/components/CO2Dashboard.js`:

```javascript
const response = await axios.get("https://co2-api.vercel.app/api/co2");
```

## Expected API Response Format

The API must return a JSON object with the following structure:

```json
{
  "co2": 450,
  "timestamp": "13/03/26, 10:30 a.m."
}
```

### Response Fields

- **co2** (number): CO2 concentration in parts per million (ppm)
- **timestamp** (string): Timestamp in format `DD/MM/YY, HH:MM a.m./p.m.`

## Customizing for Different Sensors

### Using a Local Sensor API

To connect to a local CO2 sensor, update the API endpoint in `src/components/CO2Dashboard.js:41`:

```javascript
// Replace the remote API with your local sensor endpoint
const response = await axios.get("http://192.168.1.100:8080/api/co2");
```

### Alternative Timestamp Formats

If your sensor uses ISO 8601 timestamps, modify the `formatTime` function (lines 14-36):

```javascript
const formatTime = (timestamp) => {
  const date = new Date(timestamp); // Parse ISO format directly
  return date.toLocaleTimeString('es-MX', {
    hour: '2-digit',
    minute: '2-digit',
    second: '2-digit',
    hour12: false
  });
};
```

And update the API call to use the new format:

```javascript
const { co2, timestamp } = response.data;
// No changes needed - formatTime will handle ISO format
```

### Different Response Structures

If your API returns data in a different format:

```javascript
// Example: API returns { value: 450, time: "2026-03-13T10:30:00Z" }
const response = await axios.get("your-api-endpoint");
const co2 = response.data.value;  // Extract CO2 value
const timestamp = response.data.time;  // Extract timestamp
```

## Modifying the Polling Interval

The application polls the API every 5 seconds by default. This is configured on line 63:

```javascript
const intervalId = setInterval(fetchData, 5000); // 5000ms = 5 seconds
```

### Change Polling Frequency

```javascript
// Poll every 10 seconds
const intervalId = setInterval(fetchData, 10000);

// Poll every 30 seconds
const intervalId = setInterval(fetchData, 30000);

// Poll every minute
const intervalId = setInterval(fetchData, 60000);
```

<Warning>
  Setting too short an interval may overload your sensor or API. Most CO2 sensors update readings every 1-5 seconds.
</Warning>

## Historical Data Window

The dashboard displays the last 10 data points. To show more historical data, modify lines 49 and 55:

```javascript
// Show last 20 data points instead of 10
if (newData.length > 20) newData.shift();  // Line 49

// And update timestamps accordingly
if (newTimestamps.length > 20) newTimestamps.shift();  // Line 55
```

## Error Handling

The application logs errors when the API is unreachable (line 59):

```javascript
catch (error) {
  console.error("Error fetching CO2 data:", error);
}
```

To add user-facing error messages:

```javascript
const [error, setError] = useState(null);

// In the catch block:
catch (error) {
  console.error("Error fetching CO2 data:", error);
  setError("Unable to connect to sensor");
}

// Display in the UI:
{error && <p className="error">{error}</p>}
```

## Example: Complete Local Sensor Setup

Here's a complete example for connecting to a local ESP32 sensor:

```javascript
// src/components/CO2Dashboard.js

const fetchData = async () => {
  try {
    // Connect to ESP32 on local network
    const response = await axios.get("http://192.168.1.50/sensor");
    
    // ESP32 returns: {"ppm": 450, "time": "2026-03-13T10:30:00Z"}
    const co2 = response.data.ppm;
    const timestamp = new Date(response.data.time).toLocaleTimeString();
    
    setLatestCO2(co2);
    setCo2Data((prevData) => {
      const newData = [...prevData, co2];
      if (newData.length > 10) newData.shift();
      return newData;
    });
    
    setTimestamps((prevTimestamps) => {
      const newTimestamps = [...prevTimestamps, timestamp];
      if (newTimestamps.length > 10) newTimestamps.shift();
      return newTimestamps;
    });
  } catch (error) {
    console.error("Error fetching CO2 data:", error);
  }
};

// Poll every 2 seconds for local sensor
const intervalId = setInterval(fetchData, 2000);
```
