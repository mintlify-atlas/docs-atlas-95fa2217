# Welcome to CO2 Monitor

CO2 Monitor is a Progressive Web App (PWA) designed for real-time monitoring of carbon dioxide levels in greenhouse environments. Built with React and Chart.js, it provides an intuitive, responsive interface for visualizing CO2 data across all devices.

## Technologies

CO2 Monitor is built with modern web technologies:

- **React.js** - Interactive UI library for building the dashboard
- **Chart.js** - Powerful charting library for data visualization
- **React Chart.js 2** - React wrapper for Chart.js integration
- **Axios** - HTTP client for API communication
- **PWA** - Service workers and manifest for offline capabilities
