## Overview

The `Header` component is a simple, presentational component that displays the application title. It's a stateless functional component with no props or logic.

**Location:** `src/components/Header.js`

## Implementation

The component is straightforward and concise:

```javascript
import React from "react";
import './Header.css';

function Header() {
    return (
        <header>
            <h1 className="titulo">Sistema de Monitoreo de CO2</h1>
        </header>
    );
}

export default Header;
```

## Styling

The component uses `Header.css` with the `.titulo` class:

```css
.titulo {
    font-size: 2.5em;
    color: #001d1a;
    margin-bottom: 0px;
    padding: 0px;
    font-weight: bold;
}
```

## Responsive Design

The header adapts to smaller screens with media queries:

```css
@media (max-width: 768px) {
    .titulo {
        font-size: 1.2em
    }
}

@media (max-width: 480px) {
    .titulo {
        font-size: 1.2em
    }
}
```

## Usage

Import and use the Header component at the top of your application:

```javascript
import Header from './components/Header';

function App() {
    return (
        <div className="App">
            <Header />
            {/* Other components */}
        </div>
    );
}
```

## Props

This component accepts **no props**. The title text is hardcoded in Spanish as "Sistema de Monitoreo de CO2" (CO2 Monitoring System).

<Note>
If you need to customize the title, consider passing it as a prop:

```javascript
function Header({ title }) {
    return (
        <header>
            <h1 className="titulo">{title}</h1>
        </header>
    );
}
```
</Note>
