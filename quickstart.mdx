## Overview

This guide will help you get the CO2 Monitor application running locally and displaying real-time CO2 data in just a few minutes.

## Quick Installation

<Steps>
  <Step title="Clone and navigate">
    ```bash
    git clone https://github.com/OsmelMdz/sistema-de-co2.git
    cd sistema-de-co2
    ```
  </Step>

  <Step title="Install dependencies">
    ```bash
    npm install
    ```
  </Step>

  <Step title="Start the application">
    ```bash
    npm start
    ```
    
    The application will open automatically at `http://localhost:3000`
  </Step>
</Steps>

<Note>
  The application connects to a live API endpoint at `https://co2-api.vercel.app/api/co2` and starts displaying data immediately.
</Note>

## What You'll See

Once the application loads, you'll see:

1. **Header** - "Sistema de Monitoreo de CO2" title
2. **Real-time CO2 Reading** - Large display showing current CO2 levels in ppm (parts per million)
3. **Interactive Chart** - Line graph showing the last 10 CO2 measurements updated every 5 seconds

## Understanding the Dashboard

### Real-time Updates

The dashboard automatically fetches new CO2 data every 5 seconds from the API endpoint:

```javascript CO2Dashboard.js
const intervalId = setInterval(fetchData, 5000);
```

### Data Display

The application shows:

- **Current Level**: Latest CO2 measurement in ppm
- **Historical Trend**: Rolling window of the last 10 measurements
- **Timestamps**: Formatted in 24-hour format (HH:MM:SS)

### API Response Format

The API endpoint returns CO2 data in this format:

```json
{
  "co2": 450,
  "timestamp": "13/03/26, 10:30 a.m."
}
```

### API Communication

```javascript CO2Dashboard.js
import axios from "axios";

const fetchData = async () => {
  try {
    const response = await axios.get("https://co2-api.vercel.app/api/co2");
    const { co2, timestamp } = response.data;
    setLatestCO2(co2);
    // Update chart data...
  } catch (error) {
    console.error("Error fetching CO2 data:", error);
  }
};
```

## State Management

The dashboard maintains three key state variables:

```javascript
const [co2Data, setCo2Data] = useState([]);        // Array of CO2 readings
const [timestamps, setTimestamps] = useState([]);  // Formatted timestamps
const [latestCO2, setLatestCO2] = useState(null);  // Current reading
```

Each new data point is added to the arrays, maintaining only the last 10 readings:

```javascript
setCo2Data((prevData) => {
  const newData = [...prevData, co2];
  if (newData.length > 10) newData.shift();
  return newData;
});
```

## Troubleshooting

### No Data Displayed

If the dashboard shows "Cargando..." (Loading...) indefinitely:

1. Check your internet connection
2. Verify the API endpoint is accessible: `https://co2-api.vercel.app/api/co2`
3. Check browser console for error messages

### Chart Not Rendering

If the chart area is blank:

1. Ensure Chart.js dependencies are installed
2. Check that the chart container has proper dimensions in CSS
3. Verify that data is being received (check browser console logs)

### Port Conflicts

If port 3000 is already in use:

```bash
PORT=3001 npm start
```

<Warning>
  The application requires an active internet connection to fetch CO2 data from the API endpoint. Offline functionality is limited to the cached UI.
</Warning>
